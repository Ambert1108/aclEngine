## 驱动
以Ascend-hdk-310p-npu-driver__x.x.x__linux-{arch}.run包为例说明
#### 注意事项
在软件包安装或升级过程中，不允许对Host或Device进行复位或下电操作，否则会出现Device无法正常启动或者升级失败。

### 安装
1. 将软件包（向管理员申请）上传至 "/usr/local/" 路径下
2. 登录root用户
3. 进入软件包所在路径 "cd /usr/local/"
4. 增加软件包可执行权限 `chmod +x Ascend-hdk-310p-npu-driver__x.x.x__linux-_{arch}_.run`
5. 执行如下命令，校验run安装包的一致性和完整性 `Ascend-hdk-310p-npu-driver__x.x.x__linux-_{arch}_.run --check`
	若出现如下回显信息，表示软件包校验成功。
	`Verifying archive integrity...  100%   SHA256 checksums are OK. All good.`
6. 执行如下命令，完成驱动安装，软件包默认安装路径为 “/usr/local/Ascend”
	`./Ascend-hdk-310p-npu-driver__x.x.x__linux-_{arch}_.run --full`
	若用户需要指定安装路径，如以“/test/HiAI/”为例。可执行如下命令，完成安装。
	`./Ascend-hdk-310p-npu-driver__x.x.x__linux-_{arch}_.run --full --install-path=/test/HiAI/`

	若指定路径不存在，则安装时会自动创建目录，若有多层目录，则只有最后一层目录不存在时会自动创建。
	若指定路径已存在：
    - 若该路径下所有层级目录属主为root用户，则请确保所有层级目录权限至少为755。若不满足要求，请执行如下命令修改路径权限。
        `chmod 755 路径`
    - 若该路径下有一层目录属主为非root用户，则请用户自行修改为root属主，并确保所有层级目录权限为755。若不满足要求，请执行如下命令修改路径属主为root。
        `chown root:群组名 路径`

若系统出现如下关键回显信息，则表示驱动安装成功。
`Driver package installed successfully!`

7. (可选）根据系统提示信息决定是否重启系统，若需要重启，请执行以下命令；否则，请跳过此步骤。
	`reboot`
8. 执行如下命令，查看驱动加载是否成功。
	`npu-smi info`
	若出现如下回显信息，说明加载成功，具体版本号和Device个数请以实际情况为准。否则，说明加载失败。

```
+----------------------------------------------------------------------------------------------------+
| npu-smi 24.1.rc1                            Version: 24.1.rc1                                      |
+-------------------+-----------------+--------------------------------------------------------------+
| NPU     Name      | Health          | Power(W)          Temp(C)              Hugepages-Usage(page) |
| Chip    Device    | Bus-Id          | AICore(%)         Memory-Usage(MB)                           |
+===================+=================+==============================================================+
| 4       310P3     | OK              | NA                43             0          / 970            |
| 0       0         | 0000:81:00.0    | 0                 861  / 21534                               |
+===================+=================+==============================================================+
| No running processes found in NPU 4                                                                |
+===================+=================+==============================================================+
```

> 说明
> - 安装详细日志路径：/var/log/ascend_seclog/ascend_install.log。
> - 安装后软件包的安装路径、安装命令以及运行用户信息记录路径为“/etc/ascend_install.info”。
> - 安装run包驱动时，会将动态库libdcmi.so和头文件dcmi_interface_api.h拷贝到“/usr/local/dcmi/”目录下。
> - 若创建运行用户是非HwHiAiUser，安装驱动软件包时需要指定运行用户（通过 `--install-username=_username_ --install-usergroup=_usergroup_` 参数指定）。
> - 如果服务器无BMC时，只能采用默认路径安装驱动。如果采用指定路径安装，ipmi_si驱动加载时会出现阻塞，导致磁盘挂载慢，影响npu正常运行。
> - 对于物理机不支持PCIe卡热复位场景，请使用 `./Ascend-hdk-310p-npu-driver__x.x.x__linux-_{arch}_.run --full --force` 命令安装驱动。具体参数使用请参见[参数说明/常用命令](https://support.huawei.com/enterprise/zh/doc/EDOC1100368783/f95c9664#ZH-CN_TOPIC_0000001777715426)

### 升级
1. 参照升级前准备准备驱动包“Ascend-hdk-310p-npu-driver_x.x.x_linux-{arch}.run”。

2. 登录服务器，并在root用户下执行以下操作。

3. 将“Ascend-hdk-310p-npu-driver_x.x.x_linux-{arch}.run”上传至Linux系统任意目录下，如“/usr/local/”下。  
    执行如下命令，进入软件包所在路径，如“/usr/local/”下。  
    `cd /usr/local/`

4. 执行如下命令，更改软件包权限。  
    `chmod +x Ascend-hdk-310p-npu-driver_x.x.x_linux-{arch}.run`

5. 执行如下命令，校验run安装包的一致性和完整性。  
    `./Ascend-hdk-310p-npu-driver_x.x.x_linux-{arch}.run --check`

6. 出现如下回显信息，表示软件包校验成功。  
    `Verifying archive integrity... 100% SHA256 checksums are OK. All good.`

7. 执行如下命令，完成升级操作。升级过程支持一键式升级操作。  
    `./Ascend-hdk-310p-npu-driver_x.x.x_linux-{arch}.run --upgrade`
	若系统出现如下关键回显信息，表示升级成功。  
	`Driver package upgraded successfully!`

8. （可选）根据系统提示信息决定是否重启系统，若需要重启，请执行以下命令；否则，请跳过此步骤。  
    `reboot`

9. 执行如下命令，检查升级后的版本号。  
    `/usr/local/Ascend/driver/tools/upgrade-tool --device_index -1 --system_version`

### 卸载
1. 切换至root用户
2. 在任意路径执行如下命令卸载软件包：`<install-path>/driver/script/uninstall.sh`
	install-path表示软件包安装路径，可以执行`cat /etc/ascend_install.info`命令查询安装路径
3. （可选）根据系统提示信息决定是否重启服务器，若需要重启系统，请执行以下命令；否则，请跳过此步骤。
	`reboot`

### 安装
1. 准备软件包（向管理员申请）

| 名称         | 软件包                                                  | 说明                                                         |
| ------------ | ------------------------------------------------------- | ------------------------------------------------------------ |
| 开发套件包   | Ascend-cann-toolkit_{version}linux-{arch}.run      | 主要用于用户开发应用、自定义算子和模型转换。开发套件包包含开发应用程序所需的库文件、开发工具如ATC模型转换工具。请根据CPU架构（x86_64、aarch64）获取对应的软件包。对于运行环境为aarch64而开发环境为x86_64的场景，只需获取开发环境架构的开发套件包。 |
| 二进制算子包 | Ascend-cann-kernels-{chip_type}{version}linux.run | （可选）二进制算子包，可以节省算子编译时间。在包含动态shape网络或单算子API（例如aclnn类API）场景下，需要获取该软件包。 |

2. 准备安装及运行用户
	- 运行用户：实际运行推理业务或执行训练的用户。
	- 安装用户：实际安装软件包的用户。
	  - 若使用root用户安装，支持所有用户运行相关业务。
	  - 若使用非root用户安装，则安装及运行用户必须相同。
	    - 已有非root用户，则无需再次创建。
	    - 若想使用新的非root用户，则需要先创建该用户，请参见如下方法创建。
	
	说明
	- 如果安装驱动时未携带“--install-for-all”，并且CANN软件包运行用户为非root，则该CANN软件包运行用户所属的属组必须和驱动运行用户所属属组相同；如果不同，请用户自行添加到驱动运行用户属组。
	- 运行用户不建议为root用户属组，权限控制可能存在安全风险，请谨慎使用。

3. 安装依赖（可选）
	见[链接](https://www.hiascend.com/document/detail/zh/canncommercial/80RC1/softwareinst/instg/instg_0030.html)

4. 安装开发套件
	前提条件：安装开发套件包前请确保安装目录可用空间大于9G，如不满足请清理空间或更换安装目录
	
	1. 以软件包的安装用户登录安装环境（建议使用普通账号）
	2. 将软件包上传至安装环境任意路径（如 "/home/user/package/"）
	3. 进入软件包所在路径 `cd /home/user/package/`
	4. 增加软件包可执行权限 `chmod +x Ascend-cann-toolkit_{version}_linux-{arch}.run`
	5. 执行命令校验软件包安装文件的一致性和完整性 `./Ascend-cann-toolkit_{version}_linux-{arch}.run --check`
	6. 执行安装命令 `./Ascend-cann-toolkit_{version}_linux-{arch}.run --install --quiet`
		使用 `--install-path=<path>自定义安装路径`
		安装完成后，若显示如下信息，则说明软件安装成功：
		`xxx install success`
		xxx 表示安装的实际软件包名
	7. 配置环境变量，`source ${HOME}/Ascend/ascend-toolkit/set_env.sh`

	1. 执行安装命令 `./Ascend-cann-kernels-_xxx__linux.run --install`
	
	安装完成后所在路径如下（以默认安装路径为例），用户可以在该路径下查询是否已安装二进制算子包，kernel目录存在即表示安装成功：
	- root用户：“/usr/local/Ascend/ascend-toolkit/latest/opp/built-in/op_impl/ai_core/tbe/kernel”
	- 非root用户：“_${HOME}_/Ascend/ascend-toolkit/latest/opp/built-in/op_impl/ai_core/tbe/kernel”
	其中${HOME}为当前用户目录。

> - 如果以root用户安装，**不允许安装在非root用户目录下**。

> - root用户：“/usr/local/Ascend”
> - 非root用户：“${HOME}/Ascend”
> 其中${HOME}为当前用户目录。软件包支持多版本安装，同一安装路径下，可以安装多个版
> 的软件包，不同版本的软件通过版本目录来区分。默认使用最后安装的版本（即通过软件包名/latest建立软连接到最后安装的版本）。
> - 软件包安装详细日志路径如下。
> - root用户：“/var/log/ascend_seclog/ascend_toolkit_install.log”

## MindX SDK

#### 注意事项

安装mxVision会将算子拷贝到CANN的安装路径下，因此安装mxVision后，如果卸载安装或升级CANN，会造成找不到算子，此时需要重新安装mxVision。

### 安装
1. 准备软件包（向管理员申请）

| 名称         | 软件包                                                  |
| ------------ | ------------------------------------------------------- |
| MindX SDK   | Ascend-mindxsdk-mxvision_{version}-linux-{arch}.run      |

2. 确保安装环境中已执行CANN环境变量配置脚本，使环境变量生效。
	安装toolkit包
	source $HOME_/Ascend/ascend-toolkit/set_env.sh

3. 将mxVision软件包上传到安装环境的任意路径下并进入软件包所在路径

4. 增加对软件包的权限 `chmod u+x Ascend-mindxsdk-mxvision_{version}_linux-{arch}.run`
	若显示如下信息，说明软件包满足一致性和完整性。
	`Verifying archive integrity...  100%   SHA256 checksums are OK. All good.`

5. 创建mxVision软件包的安装路径。
	- 若用户想指定安装路径，需要先创建安装路径。以安装路径“/home/user/minxsdk”为例：
	    `mkdir -p /home/user/minxsdk`
	- 若用户未指定安装路径，软件会默认安装到mxVision软件包所在的路径

6. 执行安装命令 `echo y |./Ascend-mindxsdk-mxvision_{version}_linux-{arch}.run --install --install-path=/home/user/minxsdk`

7. 安装完成后，若未出现错误信息，表示软件成功安装于指定或默认路径下。
	`Successfully installed mindx-_xxx_`

8. 环境变量生效。进入mxVision的安装路径，运行以下命令，使mxVision的环境变量生效
	`source set_env.sh`

> 说明
> - 若用户在Atlas 推理系列产品（Ascend 310P AI处理器）上使用TensorOperations相关业务，需要额外安装Ascend-cann-kernels组件。
> - 通过普通用户进行安装、运行。
> - mxVision和toolkit/nnae的安装用户需为同一用户。
> - mxVision软件包的安装用户和运行用户需为同一用户。
> - 软件包的安装升级卸载等管理面的相关日志会保存至“~/log/mindxsdk/deployment.log”，文件中保存有登录用户的用户名、访问端地址以及hostname，用于支持后续的日志跟踪及审计的操作

1. 确认mxVision目录下“bin”目录中的“uninstall.sh”脚本是否有可执行权限
2. 若脚本没有可执行权限，请执行如下命令，给予“uninstall.sh”脚本可执行权限。
	`chmod u+x uninstall.sh`
3. 执行以下任意卸载命令
```
./uninstall.sh
./Ascend-mindxsdk-mxvision_{version}_linux-{arch}.run --uninstall
```

> 说明
> 使用“uninstall.sh”脚本进行卸载操作仅适用于正常安装途径，如需解决安装异常等情况，请通过“--uninstall”方式进行卸载。



## Ascend FFmpeg

1. 创建ffmpeg第三方库路径 `ffmpeg_source`

2. 创建ffmpeg安装路径，例如`/home/zzx/tools/ffmpeg_acl`

3. 增加ffmpeg环境变量`export FFMPEG_ACL_HOME=/home/zzx/tools/ffmpeg_acl`

4. 将`${FFMPEG_ACL_HOME}/bin`添加到环境变量 `export PATH=${FFMPEG_ACL_HOME}/bin:${PATH}`

5. 下载第三方库

   ```shell
   cd ffmpeg_sources
   curl -O -L https://www.nasm.us/pub/nasm/releasebuilds/2.15.05/nasm-2.15.05.tar.bz2
   curl -O -L https://www.tortall.net/projects/yasm/releases/yasm-1.3.0.tar.gz
   git clone --branch stable --depth 1 https://code.videolan.org/videolan/x264.git
   git clone --depth 1 https://github.com/mstorsjo/fdk-aac
   curl -O -L https://downloads.sourceforge.net/project/lame/lame/3.100/lame-3.100.tar.gz
   curl -O -L https://archive.mozilla.org/pub/opus/opus-1.3.1.tar.gz
   ```

   ### nasm

   ```text
   cd ~/ffmpeg_sources
   tar xjvf nasm-2.15.05.tar.bz2
   cd nasm-2.15.05
   make clean
   ./autogen.sh
   ./configure --prefix="$FFMPEG_ACL_HOME" --bindir="$FFMPEG_ACL_HOME/bin"
   make -j8
   make install
   ```

   ### yasm

   ```text
   cd ~/ffmpeg_sources
   tar xzvf yasm-1.3.0.tar.gz
   cd yasm-1.3.0
   make clean
   ./configure --prefix="$FFMPEG_ACL_HOME" --bindir="$FFMPEG_ACL_HOME/bin"
   make -j8
   make install
   ```

   ### x264

   ```text
   cd ~/ffmpeg_sources
   cd x264 
   make clean
   PKG_CONFIG_PATH="$FFMPEG_ACL_HOME/lib/pkgconfig" ./configure --prefix="$FFMPEG_ACL_HOME" --bindir="$FFMPEG_ACL_HOME/bin" --enable-static --enable-shared --enable-pic 
   make -j16
   make install
   ```

   ### fdk-aac

   ```text
   cd ~/ffmpeg_sources
   cd fdk-aac
   make clean
   autoreconf -fiv
   ./configure --prefix="$FFMPEG_ACL_HOME"
   make -j8
   make install
   ```

   ### lame-3

   ```text
   cd ~/ffmpeg_sources
   tar xzvf lame-3.100.tar.gz
   cd lame-3.100
   make clean
   ./configure --prefix="$FFMPEG_ACL_HOME" --bindir="$FFMPEG_ACL_HOME/bin" --enable-nasm 
   make -j8
   make install
   ```

   ### opus

   ```text
   cd ~/ffmpeg_sources
   tar xzvf opus-1.3.1.tar.gz
   cd opus-1.3.1
   make clean
   ./configure --prefix="$FFMPEG_ACL_HOME" 
   make -j8
   make install
   ```

6. 将昇腾toolkit路径添加到环境变量 `export LD_LIBRARY_PATH=/home/zzx/Ascend/ascend-toolkit/latest/acllib/lib64/:$LD_LIBRARY_PATH`

7. 开始编译

   ```shell
   ./configure --prefix=/home/zzx/tools/ffmpeg_acl --enable-shared --extra-cflags="-I/home/zzx/Ascend/ascend-toolkit/latest/acllib/include -I$FFMPEG_ACL_HOME/include" --extra-ldflags="-L/home/zzx/Ascend/ascend-toolkit/latest/aarch64-linux/lib64 -L$FFMPEG_ACL_HOME/lib" --extra-libs="-lacl_dvpp_mpi -lascendcl" --enable-ascend  --enable-gpl --enable-nonfree  --enable-libfdk_aac --enable-libfreetype --enable-libmp3lame --enable-libx264 --enable-pthreads
   ```

8. 安装ffmpeg `make -j16 & make install`

9. 使用以下命令检查安装是否成功

   ```shell
   ffmpeg -encoders | grep ascend
   ffmpeg -decoders | grep ascend
   ffmpeg -hwaccels | grep ascend
   ```
